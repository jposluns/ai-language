Installation

Use Clean Language with your AI writing tool.

The repository contains one canonical skill for ChatGPT, Claude, Gemini CLI, and other large language models. The same rules handle drafting, rewriting, proofreading, adaptation, and language quality assurance.

Source repository: github.com/jposluns/ai-language

ChatGPT

  1. Download or clone the repository.
  2. Package the clean-language directory as a skill archive.
  3. Upload the resulting skill.zip through the ChatGPT Skills interface.
  4. Invoke the skill by asking ChatGPT to apply Clean Language to a draft, message, report, policy, or technical document.
python /path/to/skill-creator/scripts/package_skill.py \
  ./clean-language ./dist

The archive should contain one SKILL.md entry point and retain the relative references/ directory.

Claude Code

Copy the skill directory into the project level Claude skills directory:

mkdir -p .claude/skills
cp -R /path/to/ai-language/clean-language \
  .claude/skills/clean-language

Use the corresponding user level skills directory when you want Clean Language available across projects.

Gemini CLI

Gemini CLI supports the same Agent Skills format and can install Clean Language directly from the GitHub repository:

gemini skills install https://github.com/jposluns/ai-language.git \
  --path clean-language

The default scope installs the skill for the current user. Add --scope workspace when you want the skill limited to one project.

Verify discovery from the terminal:

gemini skills list

Inside Gemini CLI, use /skills list to inspect discovered skills and /skills reload after updating the files. Gemini loads the full Clean Language instructions only when a request matches the skill description and you approve activation.

You may also copy the skill manually to ~/.gemini/skills/clean-language for user scope or .gemini/skills/clean-language for workspace scope.

Claude Projects

Upload clean-language/SKILL.md and the files under clean-language/references/ to the project knowledge. Keep the precedence rules intact. They prevent stylistic cleanup from changing technical, legal, policy, contractual, or factual meaning.

Other AI tools and API calls

Use the contents of SKILL.md as a system instruction. Provide the reference files when the model needs detailed examples, context rules, anti patterns, or the final quality checklist.

Clean Language works with ChatGPT, Claude, Gemini, Microsoft Copilot, local models, and other systems that accept reusable instructions or project knowledge.

Prompt examples

Rewrite a draft

Apply Clean Language to this draft.
Preserve every fact, date, figure, qualification,
and technical term. Remove generic AI tone,
filler, contrast framing, and unnecessary dashes.

Audit without rewriting

Audit this document using Clean Language.
Identify robotic phrasing, filler, vague claims,
repetition, hidden ownership, and dash overuse.
Do not rewrite the text.

Prohibit em dashes and en dashes

Apply Clean Language and use no em dashes or en dashes.
Use commas, colons, parentheses, or separate sentences.

Technical and policy writing

Apply Clean Language with minimal intervention.
Preserve commands, identifiers, normative terms,
control language, and all statements of uncertainty.

Recommended operating modes

  • Draft: create finished prose from notes or an objective.
  • Rewrite: replace supplied prose while preserving meaning.
  • Proofread: correct mechanics with minimal stylistic change.
  • Audit: identify defects without rewriting.
  • Adapt: change audience, channel, tone, length, or format.
