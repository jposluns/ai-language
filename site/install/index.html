Simple installation

Pick the AI you use and follow the buttons.

You do not need a command line, a developer account, or any knowledge of GitHub. The instructions below are for the normal ChatGPT, Claude, and Gemini websites and apps.

First step: download the Clean Language instructions file. Your browser will save a small text file named clean-language-instructions.txt.

ChatGPT

Use this method when your ChatGPT account shows Plugins and Skills. Personal Skills are generally available on Business, Enterprise, Healthcare, and Edu accounts. Your workspace administrator may need to enable them.

  1. Open ChatGPT.
  2. Look at the menu on the left and click Plugins.
  3. At the top of the Plugin Directory, click Skills.
  4. Click Create.
  5. Click Create with chat.
  6. Type: Create a skill named Clean Language using the instructions in the file I am about to upload.
  7. Attach the downloaded clean-language-instructions.txt file.
  8. Send the message.
  9. When ChatGPT shows the completed skill, click Install.

Test it by starting a new chat and typing: Apply Clean Language to this message: [paste your text]

Do you not see Plugins or Skills? Your account may not support personal Skills yet, or your organization may have disabled them. Use the instructions file in a normal chat and say: Follow these writing rules for this conversation.

Claude website or Claude Desktop

The easiest non-technical method is a Claude Project. Projects are available on paid Claude plans and keep the instructions available for every chat inside that project.

  1. Open Claude.
  2. Move your pointer to the left side of the screen and click Projects.
  3. Click New Project.
  4. Name the project Clean Language.
  5. Open the new project.
  6. On the right side, find Project knowledge.
  7. Click the + button.
  8. Choose the downloaded clean-language-instructions.txt file.
  9. Click Set project instructions.
  10. Paste this sentence: Use the Clean Language instructions in project knowledge for every response unless I explicitly tell you not to.
  11. Click Save instructions.

Start all writing chats inside the Clean Language project. Claude will use the file automatically within that project.

Gemini website or Gemini app

The easiest method is a custom Gem. Create it once on the Gemini website, then use it from the Gemini website, mobile app, or supported Google Workspace side panel.

  1. On a computer, open gemini.google.com.
  2. Open the menu on the left.
  3. Click Gems. If you do not see it, click Settings and help, then Gems.
  4. Click New Gem.
  5. Name it Clean Language.
  6. In the instructions box, type: Follow the Clean Language instructions in the attached knowledge file for every response.
  7. Scroll to Knowledge.
  8. Click Add files.
  9. Click Upload files.
  10. Select clean-language-instructions.txt.
  11. Click Save.

To use it later, open Gemini, click Gems, then click Clean Language.

Mobile note: Custom Gems are created and edited on the Gemini website. After saving, the Gem appears in the Gemini mobile app.

How to use Clean Language

You can paste rough notes or finished text. Use one of these simple requests:

Rewrite this using Clean Language:
[paste text]
Proofread this using Clean Language.
Fix mistakes but do not change my tone:
[paste text]
Audit this for robotic AI language,
filler, contrast framing, and dash overuse.
Do not rewrite it:
[paste text]
Write this with no em dashes or en dashes:
[paste notes]

For technical users

Developers can install the full Agent Skill from the GitHub repository for ChatGPT, Claude Code, or Gemini CLI. Ordinary users do not need this method.

Clean Language is open source software created by Jeff Posluns.
