Site web Claude ou Claude Desktop

Dernière vérification le 27 juillet 2026.

C'est la méthode recommandée pour Claude. Elle installe le Skill complet, de sorte que Claude utilise les instructions et fichiers de référence canoniques dans chaque conversation plutôt que dans un seul projet.

D'abord, activez l'exécution de code. La section Skills n'apparaît pas sans cela.

Sur les forfaits Free, Pro et Max, ouvrez Paramètres, puis Capacités et activez Exécution de code et création de fichiers. Si la section Skills manque encore par la suite, ce paramètre en est la cause.

Installez depuis un navigateur de bureau. Les applications mobiles ne sont pas documentées comme prenant en charge le téléversement de Skills.

Étape 1 : télécharger le Skill

Télécharger clean-language.zip Comment vérifier ce téléchargement (facultatif)

Votre navigateur enregistre un fichier nommé clean-language.zip. Ne le décompressez pas. Le Skill n'est que des instructions en prose et du matériel de référence. Il ne contient aucun code exécutable et n'effectue aucun appel réseau.

Étape 2 : le téléverser dans Claude

Ouvrir les Skills de Claude

Sur la page Skills :

  1. Cliquez sur le bouton +, puis + Créer un Skill.
  2. Cliquez sur Téléverser un Skill.
  3. Sélectionnez le fichier clean-language.zip téléchargé.
  4. Assurez-vous que Clean Language est activé dans votre liste de Skills.

Testez-le dans une nouvelle conversation. Copiez cette invite, collez-la, puis ajoutez votre texte :

Applique Clean Language à ce brouillon :
Team ou Enterprise : un propriétaire d'organisation doit activer à la fois Exécution de code et création de fichiers et Skills dans Paramètres de l'organisation, puis Skills. Un propriétaire peut téléverser Clean Language une seule fois pour le provisionner pour toute l'organisation, après quoi il apparaît automatiquement pour chaque membre, qui n'a pas à le téléverser individuellement.
Solution de repli : utiliser un projet Claude à la place

N'utilisez ceci que si votre organisation a désactivé les Skills ou l'exécution de code. Cela s'applique à un seul projet plutôt qu'à chaque conversation.

  1. Télécharger les instructions Voir l'original sur GitHub
  2. Dans Claude, cliquez sur Projets, puis Nouveau projet.
  3. Nommez-le Clean Language.
  4. Sous Connaissances du projet, cliquez sur + et téléversez le fichier enregistré.
  5. Réglez les instructions du projet à : Utilise les instructions Clean Language dans les connaissances du projet pour chaque réponse, sauf si je te dis explicitement le contraire.

ChatGPT

Dernière vérification le 27 juillet 2026.

ChatGPT peut utiliser le même Skill packagé que Claude. Téléversez-le une fois, et ChatGPT applique Clean Language lorsque votre demande correspond.

Étape 1 : télécharger le Skill

Télécharger clean-language.zip Comment vérifier ce téléchargement (facultatif)

Votre navigateur enregistre un fichier nommé clean-language.zip. Ne le décompressez pas. Le Skill n'est que des instructions en prose et du matériel de référence. Il ne contient aucun code exécutable et n'effectue aucun appel réseau.

Étape 2 : le téléverser dans ChatGPT

  1. Ouvrez Plugins dans la barre latérale de ChatGPT, puis ouvrez Skills.
  2. Cliquez sur Créer, puis Téléverser depuis votre ordinateur.
  3. Sélectionnez le fichier clean-language.zip téléchargé.
  4. Passez le Skill en revue, puis installez-le.

Testez-le dans une nouvelle conversation : Applique Clean Language à ce message : [collez votre texte]

Comptes Workspace : votre administrateur devra peut-être autoriser les membres à utiliser et téléverser des Skills.
Solution de repli : construire le Skill à partir du fichier d'instructions

Utilisez ceci si votre compte ne peut pas téléverser de Skill.

  1. Télécharger les instructions Voir l'original sur GitHub
    Le fichier s'enregistre sous clean-language-instructions.txt.
  2. Ouvrez ChatGPT, ouvrez Plugins, puis Skills.
  3. Cliquez sur Créer, puis Créer par conversation.
  4. Tapez : Crée un Skill nommé Clean Language en utilisant les instructions du fichier que je vais téléverser.
  5. Joignez clean-language-instructions.txt et envoyez le message.
  6. Lorsque ChatGPT affiche le Skill terminé, installez-le.

Si vous ne voyez pas Skills, joignez le fichier d'instructions à une conversation normale et dites : Suis ces règles d'écriture pour cette conversation.

Site web Gemini ou application Gemini

Dernière vérification le 27 juillet 2026.

La méthode réutilisable la plus simple est un Gem personnalisé. Créez-le une fois sur le site web Gemini, puis utilisez-le depuis le site, l'application mobile, ou le panneau latéral Google Workspace pris en charge.

  1. Télécharger les instructions Voir l'original sur GitHub
    Le fichier s'enregistre sous clean-language-instructions.txt.
  2. Sur un ordinateur, ouvrez gemini.google.com.
  3. Ouvrez le menu à gauche.
  4. Cliquez sur Gems. Si vous ne le voyez pas, cliquez sur Paramètres et aide, puis Gems.
  5. Cliquez sur Nouveau Gem.
  6. Nommez-le Clean Language.
  7. Dans la zone d'instructions, tapez : Suis les instructions Clean Language du fichier de connaissances joint pour chaque réponse.
  8. Faites défiler jusqu'à Connaissances.
  9. Cliquez sur Ajouter des fichiers, puis Téléverser des fichiers.
  10. Sélectionnez clean-language-instructions.txt.
  11. Cliquez sur Enregistrer.

Pour l'utiliser plus tard, ouvrez Gemini, cliquez sur Gems, puis cliquez sur Clean Language.

Remarque mobile : créez et modifiez le Gem sur le site web Gemini. Une fois enregistré, le Gem apparaît dans l'application mobile Gemini.

Copilot

Dernière vérification le 27 juillet 2026.

La méthode réutilisable est un agent Copilot. Créez-le une fois avec Agent Builder, puis sélectionnez-le chaque fois que vous écrivez. Créer un agent avec un fichier de connaissances téléversé nécessite une licence Microsoft 365 Copilot.

  1. Télécharger les instructions Voir l'original sur GitHub
    Le fichier s'enregistre sous clean-language-instructions.txt.
  2. Ouvrez Microsoft 365 Copilot sur un ordinateur.
  3. Ouvrez le panneau des agents et cliquez sur Nouvel agent, puis ouvrez l'onglet Configurer.
  4. Nommez-le Clean Language.
  5. Dans la zone d'instructions, entrez : Suis les instructions Clean Language du fichier de connaissances téléversé pour chaque réponse.
  6. Sous Connaissances, téléversez clean-language-instructions.txt depuis votre appareil.
  7. Cliquez sur Créer ou Enregistrer, puis sélectionnez Clean Language chaque fois que vous en avez besoin.
Pas d'accès aux agents ? Collez le contenu de clean-language-instructions.txt dans une conversation Copilot et dites : Suis ces règles d'écriture pour cette conversation.

Autres systèmes IA

Clean Language fonctionne aussi avec les modèles locaux, les assistants basés sur une API, et les autres systèmes qui acceptent des instructions personnalisées, des invites système, des connaissances réutilisables, ou des fichiers téléversés.

  1. Télécharger les instructions Voir l'original sur GitHub
  2. Enregistrez le fichier ou copiez son contenu.
  3. Ajoutez-le à votre outil IA comme instructions personnalisées, connaissances de projet, invite système, ou fichier de référence joint.
  4. Dites à l'IA : Utilise les instructions Clean Language pour chaque réponse, sauf si je te dis explicitement le contraire.

Pour les utilisateurs techniques

Les développeurs peuvent installer le Skill Agent complet depuis le dépôt GitHub pour ChatGPT, Claude Code, Gemini CLI, et les clients Agent Skills compatibles.

Confiance et assurance

  • Le Skill ne contient aucun code exécutable et n'effectue aucun appel réseau.
  • Chaque règle et fichier de référence est vérifiable publiquement dans le dépôt GitHub.
  • Chaque version étiquetée fournit une somme de contrôle SHA-256, afin de vérifier le téléchargement.
  • Clean Language est sous licence CC BY-SA 4.0.
  • Clean Language est le même ensemble d'instructions sur chaque plateforme, mais chaque fournisseur contrôle la façon dont son modèle les applique, donc les résultats varient d'une plateforme à l'autre.
  • Un modèle peut tout de même changer le sens même avec ces règles en place, alors lisez le résultat avant de vous y fier.
  • Pour un texte juridique, médical, financier, lié à la sécurité, ou à enjeu élevé, faites réviser toute modification par une personne qualifiée.
  • Qu'une plateforme applique le Skill automatiquement ou seulement lorsque vous le demandez varie selon la plateforme et le compte.
