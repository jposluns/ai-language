Facultatif

Vérifiez votre téléchargement.

Cette étape est facultative. Si vous faites confiance à la source, soit la version officielle de Clean Language sur GitHub, installez le Skill sans rien vérifier. La vérification existe pour les personnes qui veulent confirmer, pour leur propre tranquillité d'esprit, que le fichier est arrivé exactement tel que publié.

Devez-vous faire cela ?

Non. Le téléchargement fonctionne de la même façon dans les deux cas. La vérification ajoute de la confiance pour les personnes soucieuses de sécurité, et pour quiconque se trouve sur un réseau non fiable et veut écarter un fichier corrompu ou modifié. Si ce n'est pas une préoccupation pour vous, ignorez cette étape et suivez le guide d'installation.

Qu'est-ce qu'une somme de contrôle

Une somme de contrôle SHA-256 est une courte empreinte d'un fichier. Le même fichier produit toujours la même empreinte, et changer ne serait-ce qu'un seul octet en produit une différente. Chaque version de Clean Language publie la somme de contrôle de clean-language.zip. Si la somme de contrôle que vous calculez pour votre copie correspond à la valeur publiée, votre téléchargement est identique à la version publiée et vous est parvenu intact.

Comment vérifier

  1. Téléchargez le Skill et sa somme de contrôle publiée.
    Télécharger clean-language.zip Somme de contrôle publiée
  2. Calculez la somme de contrôle du fichier téléchargé. Ouvrez un terminal dans le dossier contenant clean-language.zip et exécutez la commande pour votre système.

    Windows (PowerShell)

    Get-FileHash clean-language.zip -Algorithm SHA256

    macOS

    shasum -a 256 clean-language.zip

    Linux

    sha256sum clean-language.zip
  3. Comparez la valeur affichée par votre ordinateur avec celle de clean-language.zip.sha256. Une correspondance signifie que le téléchargement est authentique. En cas de différence, supprimez le fichier, téléchargez-le à nouveau, et vérifiez une seconde fois.

Pourquoi il est sûr d'ignorer cette étape

Le Skill n'est que des instructions en prose et du matériel de référence. Il ne contient aucun code exécutable, n'effectue aucun appel réseau, et chaque fichier est vérifiable publiquement dans le dépôt GitHub. La somme de contrôle confirme que le fichier est arrivé intact. Le Skill est sûr à utiliser, que vous le vérifiiez ou non.
